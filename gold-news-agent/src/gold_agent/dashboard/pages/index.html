        Indikator Gold News Agent

        Indikator yang sama dengan script TradingView, digambar langsung dari alat ini: zona entry, SL, TP1–TP3 sinyal aktif, warna sesi (biru London, ungu New York, oranye overlap, abu-abu jeda harian), tanda Data AS 08:30 New York, serta penanda berita dan sinyal. Harga dari feed alat ini (PAXG bila belum memakai MT5), jadi level sinyal pas tanpa digeser.

        Proyeksi 24 jam (kanan candle terakhir, garis putus-putus + pita): ramalan alat berita, bukan harga. Arah tiap jam dari bias Outlook (hijau naik, merah turun, abu-abu netral/TUNGGU DATA) dikali confidence; lebar pita = perkiraan rentang gerak jam itu; saat ada sinyal aktif, garis menuju TP1 sampai sinyal kedaluwarsa. Titik oranye = jadwal rilis data. Pita pudar = jam bersyarat (> 4 jam ke depan).

        Cara memasang indikator "Gold News Agent" di TradingView
        1. Klik Salin script indikator di atas.
        2. Di TradingView buka Pine Editor (tab di bawah grafik), pilih Open → New indicator, hapus isinya, tempel (Ctrl+V).
        3. Klik Save (beri nama Gold News Agent), lalu Add to chart.
        4. Saat ada sinyal, salin Kode TradingView dari Telegram atau menu Live, lalu di grafik: ikon roda gigi indikator → Kode sinyal → tempel → OK.
